# 🧭 PM Compass

**A free, single-file learning and decision app for project managers and operations managers.** Choose the right methodology, learn how each one runs, see the reports and meetings that coordinate the work, and practise for interviews.

> **Golden rule:** a finalised plan with fixed cost, fixed scope and fixed date belongs to **Waterfall** (or PRINCE2 with strict change control). Using Agile there is where projects break.

## What's inside

| Tab | What you get |
|---|---|
| Choose method | 6-question wizard recommending Waterfall, PRINCE2, PMP, Agile/Scrum, Kanban or Hybrid |
| Methodologies | Comparison table, team roles, when to use or avoid, reports used |
| Project chart | Stage-by-stage timeline showing how each project starts, runs and closes |
| Scrum daily | Daily Scrum, sprint events, roles, common mistakes |
| Reports | Daily, weekly, monthly and stage-gate reports, RAG rules |
| Risk | Process, register fields, probability × impact scorer |
| Budget & billing | Budgeting, billing models, Earned Value calculator (CPI, SPI, EAC) |
| Stakeholders | Needs, channels and rhythm per stakeholder |
| A to Z | 26 essentials for project and operations managers |
| AI & manpower | Where AI and automation save effort, and a learn-to-work path |
| Learn / videos | 12 topics linked to live YouTube searches |
| Interview prep | 25 interview questions with model answer hints, filterable by topic |

## Run it

No build, no dependencies, no server.

1. Download `index.html` (rename `pm-compass.html` to `index.html`).
2. Open it in any browser.

### Publish free with GitHub Pages

1. Create a repo and upload `index.html` and this `README.md`.
2. Go to **Settings → Pages**.
3. Set source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Your app will be live at `https://<your-username>.github.io/<repo-name>/`.

## Customise

- Edit methodology content in the `M` object.
- Edit interview questions in the `IQ` array.
- Edit video topics in the `LEARN` array.
- Edit the A to Z list in the `AZ` array.

## Notes

- Video links open YouTube searches so they never go stale.
- AI time-saving figures are indicative; test in your own context.
- Educational guidance only. Tailor methods to your organisation and contracts.
